# Quarzo Life

**Building the European technology backbone that makes digital life insurance distribution easier and faster.**

We’re building an API-native Core Insurance System to help financial platforms and distribution partners integrate, distribute, and manage savings-oriented life insurance.

Our ambition is to make life insurance a seamless part of the digital wealth experience — with simpler integrations, real-time interactions, and flexible products built around customers’ needs.

## What drives our engineering

* **APIs first** - make integration a core capability.
* **Event-driven architecture** - keep systems connected as business events happen.
* **Precision by design** - handle money and fractional holdings with explicit, reliable arithmetic.
* **Composable software** - build focused components with clear responsibilities.

## Open source

We share reusable libraries for developers building financial applications and TypeScript services.

| Project                                             | What it does                                                                                                                                    |
| :-------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------- |
| **[Moneta](https://github.com/quarzo-life/moneta)** | Create, calculate, and format monetary values in JavaScript and TypeScript using `bigint`. Adapted from Dinero.js v2.                           |
| **[Portio](https://github.com/quarzo-life/portio)** | Represent and calculate fractional share quantities using `bigint` and explicit decimal scales.                                                 |
| **[fp](https://github.com/quarzo-life/fp)**         | Lightweight, dependency-free functional programming utilities for TypeScript, including composition, typed results, and asynchronous workflows. |

All three libraries are released under the **MIT license** and published on **[JSR](https://jsr.io/@quarzo-life)**.

Issues, feedback, and pull requests are welcome - head to the relevant repository to get involved.
